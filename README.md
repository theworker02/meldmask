# meldmask

Meld color mask values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/meldmask/

## Install / run

```bash
git clone https://github.com/theworker02/meldmask.git
cd meldmask
node src/cli.js
node --test
```
